# Push this GitHub profile to sujalnaik20/sujalnaik20

Everything is ready: README.md, exact original PNGs, and the Pac-Man GitHub Actions workflow.

## Option A — upload in GitHub's browser
1. Create the PUBLIC repository named `sujalnaik20` under your `sujalnaik20` account if it doesn't exist.
2. Upload `README.md` and `assets/dreaming.png`, `assets/planet.png` preserving the folder structure.
3. Create `.github/workflows/pacman.yml` and paste the workflow file content.
4. Go to Settings > Actions > General > Workflow permissions. Enable 'Read and write permissions' if necessary and permitted.
5. Go to Actions > Update Pac-Man Contribution > Run workflow (main). Wait for the output branch to be generated.
6. Open https://github.com/sujalnaik20 to see your profile.

## Option B — command line (for a new, empty GitHub repo)
Open a terminal INSIDE this extracted folder and run:

git init
git branch -M main
git add README.md assets .github
git commit -m "Build visual GitHub profile with Pac-Man activity"
git remote add origin https://github.com/sujalnaik20/sujalnaik20.git
git push -u origin main

If the repository already contains files or commits, clone it first, copy these files into the clone, then git add / commit / push from that clone. Do not force push.
